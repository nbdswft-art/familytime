# منيو فاملي تايم

موقع منيو مطعم وحدائق فاملي تايم. يشتغل على GitHub Pages، والبيانات والإحصائيات ودخول الأدمن على Supabase.

- المنيو للزبائن: `index.html`
- لوحة التحكم: مجلد `k2c011b6702/` (تحتاج إيميل وكلمة سر من Supabase، والحساب لازم يكون بجدول `fm_admins`)
- إعداد قاعدة البيانات: `supabase/setup.sql` (يتشغّل مرة وحدة من SQL Editor)

## الحماية
- كلمة السر ما موجودة بالكود؛ Supabase يتحقق منها بالسيرفر.
- الكتابة على المنيو والسجل والنسخ الاحتياطية والإحصائيات مسموحة بس للأدمن (RLS).
- الزبون يكدر بس يقرا المنيو ويضيف حدث إحصائي بدون معلومات شخصية.
- المفتاح بـ `assets/config.js` هو مفتاح "publishable" ومسموح يكون علني.
